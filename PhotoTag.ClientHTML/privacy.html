Zásady ochrany soukromí

1. Kdo spravuje data?

  • Self-hosted: Pokud si hostujete vlastní server, autor aplikace k vašim datům nemá přístup. Správcem je provozovatel dané instance.
  • Centrální server: Správcem je autor aplikace (T0biasCZe).

2. Jaká data se zpracovávají?

  • Centrální server E-mail: Pouze pro verifikaci účtu a obnovu hesla.
  • Centrální server Logy: IP adresa a model zařízení pro účely zabezpečení a diagnostiky.
  • Obecné GPS poloha: Ukládá se k záznamům pro potřeby geotaggingu.
  • Obecné Náhledová fotografie: Volitelně lze k záznamu uložit malý snímek pro snazší pozdější identifikaci.

3. Služby třetích stran

  • Klientská aplikace Mapy.cz: Mapové podklady se stahují přímo ze serverů Seznamu. Zásady soukromí.
  • Centrální server Cloudflare: Zabezpečení provozu centrálního serveru. Zásady soukromí.

4. Vaše práva

Při používání centrálního serveru máte dle GDPR právo na výmaz dat: phototag@tobikcze.eu

Privacy Policy

1. Data Responsibility

  • Self-hosted: You control your data. The developer has no access. The instance admin is the data controller.
  • Central Server: Data is managed by the developer (T0biasCZe).

2. Data Collection & Scope

  • Central Server Email Address: For account verification and recovery.
  • Central Server Service Logs: IP address and device model logged for security and debugging.
  • All GPS Location: Stored with each entry for geotagging purposes.
  • All Thumbnail: Optionally, a small photo can be stored alongside each tag for easier identification.

3. Third-Party Services

  • Client App Mapy.cz: Fetches map tiles directly. Your IP is shared with Seznam.cz. Privacy Policy.
  • Central Server Cloudflare: Secure network tunneling for the official instance. Privacy Policy.

4. Your Rights

If using the central server, you have the right to data deletion (GDPR): phototag@tobikcze.eu
